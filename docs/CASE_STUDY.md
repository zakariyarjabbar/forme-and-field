# FORME & FIELD — portfolio case study draft

FORME & FIELD is a fictional furniture and lighting studio built to demonstrate both storefront design and a complete commerce workflow. The problem was to make a store feel like an architectural interiors publication while keeping product selection, delivery costs and order status easy to understand.

The visual direction uses chalk surfaces, olive-charcoal text, an oxblood action colour, Newsreader display typography and Manrope interface text. Large room photographs lead into a quieter object catalog. Three rooms connect the editorial imagery to the pieces shoppers can select. Product pages combine an open gallery, explicit finish swatches and material details with clear dimensions and availability.

The catalog contains 24 fictional products across seating, tables, lighting, storage and objects. Original AI-generated imagery maintains the principal featured product shapes across catalog views and room scenes. Images represent design concepts; they are not photographs of actual manufactured goods. Native product panels are 512×512 and this limits fine-detail zoom.

The commerce demonstration stores its data locally in each visitor’s browser and uses a credential-free payment simulator. A visitor can save pieces, place a successful or declined demo order, inspect the resulting order and manage it from the merchant view. Catalog, stock, inquiries and local message previews are part of the same isolated workspace. Copy-on-write snapshots and cross-tab Web Locks preserve simulated inventory and idempotent order creation. This is browser-editable portfolio data, without a server database or real authentication.

This is a concept portfolio project. No real customers, commercial results, revenue, conversion lift, awards, manufacturing or product sales are claimed. See QA.md for measured validation results and remaining limitations.
